# Mobbin Product Pattern Research

Use this skill for real-product flow and interaction-pattern research from Mobbin.

## Required behavior
- Focus on navigation, onboarding, search, forms, checkout/order flows, dashboards, tables, filters, sheets, dialogs, empty/loading/error states and mobile interaction patterns.
- Compare multiple products when possible rather than cloning one product.
- Return a pattern matrix: problem, observed solution, strengths, weaknesses, adaptation for NeginAI, source link.
- Prioritize production-realistic UX over marketing polish.

## Guardrails
- Never bypass login, paywalls, robots, rate limits or access controls.
- Do not reproduce proprietary screenshots or screens as implementation targets.
- Preserve NeginAI canonical feature semantics, role model, RTL, accessibility, mobile-first architecture and bottom-navigation rules.
