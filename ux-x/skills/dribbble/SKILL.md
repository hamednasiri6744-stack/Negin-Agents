# Dribbble Pattern Research

Use this skill for targeted UI inspiration and visual-pattern research from Dribbble.

## Required behavior
- Treat Dribbble as an external reference source, never as the NeginAI product authority.
- Extract reusable patterns: hierarchy, layout, composition, component treatment, interaction cues, motion ideas, spacing, typography relationships and visual-token ideas.
- Synthesize across multiple references where possible.
- Return source links for references used.
- Explicitly separate production-realistic patterns from presentation-only styling.

## Guardrails
- Never copy a shot pixel-for-pixel.
- Never extract or reuse proprietary assets, illustrations or branding.
- Never bypass login, paywalls, robots, rate limits or access controls.
- Preserve NeginAI canonical visual identity, feature semantics, RTL, accessibility and mobile-first constraints.
