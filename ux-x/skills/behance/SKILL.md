# Behance Case Study Research

Use this skill for long-form product-design, design-system, brand-system, motion and case-study research from Behance.

## Required behavior
- Extract design rationale, system structure, layout principles, component language, motion principles and presentation-vs-production tradeoffs.
- Return reusable principles and source links.
- Flag ideas that are visually impressive but operationally weak for enterprise software.
- Adapt findings to NeginAI rather than changing NeginAI to match the reference.

## Guardrails
- Never copy case studies, mockups, illustrations or branded assets.
- Never bypass access controls, login, paywalls, robots or rate limits.
- NeginAI canonical product/visual rules remain authoritative.
- Preserve accessibility, RTL, performance and production realism.
