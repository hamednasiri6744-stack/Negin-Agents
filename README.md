# Negin Agents

Source repository for Negin-Master, Code-X, UX-X, Data-X, Automation-X and the Unified Gateway.

## Layout
- negin-master
- code-x
- ux-x
- data-x
- automation-x
- shared/specialist-host
- gateway

Local machine configuration and runtime state are intentionally not part of this repository.

Runtime versions can be upgraded independently while connector identities remain stable; deploy, reconnect and verify health after upgrades.
